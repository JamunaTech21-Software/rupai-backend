# Core

Cross-cutting mechanisms that every module depends on. Modules call these. These never import from `src/modules`.

| Folder          | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Delivered in |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| `context/`      | Per-request context (AsyncLocalStorage): request id, request logger, actor, session and must-change-password flag (P1.02); later the scope                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | P0.02        |
| `logging/`      | Pino root logger, redaction of secrets/NIDs/bank details, `getLogger()` for request-bound logging                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | P0.02        |
| `db/`           | Prisma client (app account, ReadCommitted, scope extension), keyset cursor paging (`idCursorPage`), `withTransaction`, `lockRowsForUpdate`, `quoteIdentifier`, seeders and `seedRows` (single or composite key); `constraintViolation` (unique / referenced / CHECK → API errors) and `toWhere`/`toOrderBy`/`toPaging` for list queries (P1.01)                                                                                                                                                                                                                                                                                                                                                                              | P0.03        |
| `http/`         | Response envelope, list-query grammar (filter/sort/include/fields/pagination), Zod `validate`, If-Match concurrency, Idempotency-Key, rate-limit classes, `/health`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | P0.04        |
| `http/` (cont.) | `defineModule`/`route` declarations checked at start-up, OpenAPI 3.1 generation from the Zod schemas, `/docs` (Swagger UI), Redis idempotency store; **P1.08:** `masterItemRoutes` (GET/PUT/PATCH/DELETE + deactivate/reactivate for every master)                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | P0.07        |
| `redis/`        | ioredis client (`rupai:` key prefix, no offline queue) and its readiness check                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | P0.07        |
| `platform.ts`   | Where idempotency records and rate-limit counters live: Redis when `REDIS_URL` is set, else in memory                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | P0.07        |
| `money/`        | `Dec` decimal type (40 digits, half-up), `parseDecimal`/`zDecimal` per kind (money 4 dp, qty 3, rate 8, pct 4), `roundMoney`, `divide` (refuses ÷0), `allocate` (difference to the largest line), `splitInstalments`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | P0.05        |
| `ids/`          | Monotonic ULIDs (`newUlid`, `isUlid`, `zUlid`) and BIGINT-as-string ids (`zId`, `parseId`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | P0.05        |
| `time/`         | Business dates without drift (`businessDateFromDb/ToDb`, `todayIn`, `addDays`, `daysInMonth`, `zBusinessDate`) and offset-bearing timestamps (`zTimestamp`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | P0.05        |
| `errors/`       | `AppError` hierarchy with stable error codes → HTTP status (Spec P4 §3)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | P0.04        |
| `auth/`         | **P1.01:** argon2id password hashing (`hashPassword`, `verifyPassword`, `needsRehash`, `zPassword`), `requirePermission` and `PermissionResolver` (effective permissions resolved per request), `currentActorId`. **P1.02:** `tokenSigner` (HS256 access tokens, previous-key rotation), `sessionStore` (session state cached in Redis with a DB fallback, revocation with tombstones), `authenticate` (bearer token + live session on every request), `requireSignedIn`, `PASSWORD_CHANGE_REQUIRED` gate                                                                                                                                                                                                                    | P1.01–P1.02  |
| `mail/`         | `createMailer` (SMTP via nodemailer, or the log outside production), `memoryMailer` for tests                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | P1.02        |
| `scope/`        | **P1.03:** `ResolvedScope` and `scopeFromGrants` (union of live grants + implicit self), `currentScope`/`appliedScope`/`runUnscoped`; `SCOPED_MODELS` registry with `byColumn` and relation mappings; the Prisma **scope extension** (filters every query on a scoped model, refuses out-of-scope creates, throws without a scope); `scopeSql` for raw queries; `SCOPE_TARGETS` grant-target checks. **P1.07:** `createsCheckedBy: 'service'` for models whose creates need the parent, `scopeToCheck()` for write-level checks in services. **P1.08:** facility grants are `factory` and `warehouse` (two types, not one `facility`)                                                                                        | P1.03        |
| `audit/`        | **P1.05:** `auditCreate`/`auditUpdate`/`auditDelete`/`auditAction` and `recordStatusChange` (same transaction as the change, depth by record class, values as stable text); `dbAccessLog` (auth events and denials, outside the transaction); `logIntegration`. Scope denials are logged by the scope extension                                                                                                                                                                                                                                                                                                                                                                                                              | P1.05        |
| `rules/`        | **P1.06:** the effective-dated rule block, shared by every rule table (P3 §17.1). `defineRuleTable` (scope dimensions with power-of-two weights → specificity), `ruleTableSql` migration helper (generated `specificity` and `active_key`, CHECKs, UPDATE-only grant; `scripts/rule-table-sql.ts`) and `checkRuleTable`; `resolveRule` (one indexed query, `RULE_NOT_FOUND` / `RULE_AMBIGUOUS`), pure `pickRule`, `explainRule` for `/resolve`; `ruleVersions` (draft → submitted → active → superseded, supersede closes the previous version on approval, `RULE_OVERLAP`, retrospective flag + elevated approval, no self-approval, audit + status history, estate scope). Register tables in `src/modules/rule-tables.ts` | P1.06        |
| `approval/`     | Workflow engine: selection, frozen path, approver resolution, actions (Spec P7)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | P1.13–P1.14  |
| `jobs/`         | Queue, idempotent job contract, job resource, singleton scheduler (Spec P4 §5.3)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | P1.15        |
| `storage/`      | Document storage abstraction on local disk with relative paths (Spec P1 §5.23)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | P1.12        |
| `posting/`      | The single posting engine and `posting_link` idempotency guard (Spec P1 §7.2)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | P3.03        |
| `stock/`        | The single stock movement service and weighted-average cost (Spec P1 §7.4, §8)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | P4.04        |
